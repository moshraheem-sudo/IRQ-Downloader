Ezoo Download uses the following open source components.

Slint (user interface toolkit) - https://slint.dev
  Used under the Slint Royalty-free Desktop, Mobile, and Web Applications License 2.0.

yt-dlp - https://github.com/yt-dlp/yt-dlp
  The Unlicense (public domain).

FFmpeg - https://github.com/FFmpeg/FFmpeg
  The FFmpeg program in the "tools" folder is an unmodified build from
  https://github.com/BtbN/FFmpeg-Builds licensed under the GNU General Public
  License version 3 (see ffmpeg-LICENSE.txt in the "tools" folder).
  Its source code is available at https://github.com/FFmpeg/FFmpeg.

aria2 - https://github.com/aria2/aria2
  The aria2c program in the "tools" folder (used for BitTorrent download engine)
  is an unmodified release build licensed under the GNU General Public License
  version 2 or later (see aria2-COPYING.txt in the "tools" folder). Its source
  code is available at https://github.com/aria2/aria2.

BitTorrent & Libtorrent Architecture References - https://github.com/arvidn/libtorrent
  The BitTorrent engine integration, peer wire specs, and bencode parsing protocols
  follow the specifications and architectural patterns referenced from libtorrent
  (BSD-3-Clause) and official BitTorrent BEPs.

PyQt6 - https://riverbankcomputing.com/software/pyqt/
  GPL v3 license.

Rust crates (tokio, reqwest, serde, chrono, tiny_http, arboard, rfd, tray-icon,
regex, sha2, aes, cbc, url, directories, filetime and their dependencies)
  MIT and/or Apache-2.0 licenses.
